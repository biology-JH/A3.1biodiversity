A3.1.10 · DATABASE SKILL

Compare genome-size records

Look up one plant and one animal in the Kew C-values database or the Animal Genome Size Database. Record each organism, 1C value, unit and database record/date.

  1. Compare their DNA amounts with the interactive chart and state which genome is larger.
  2. Use a unicellular and multicellular example. Does DNA amount reliably rank organismal complexity?
  3. Explain why repeats, transposons or polyploidy can change C-value without a matching change in gene number.

Check that both records refer to a haploid nuclear genome; note the source and release because measurements can differ.
